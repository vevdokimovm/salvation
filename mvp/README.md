# MVP — дневник практики

Один файл, `index.html`. Ни сборки, ни сервера, ни зависимостей: открывается
двойным щелчком в любом браузере.

## Что делает

- **Сегодня** — восемь параметров, у каждого свой вопрос и поле для записи.
  Оценок нет: только текст, только про то, что было.
- **Практика** — сколько дней прошло с исповеди и причастия; сколько дней
  из тридцати читался канон и Писание.
- **История** — сетка за тридцать дней: тёмная клетка = в этот день была запись.
  Ниже — сами записи.

## Чего нет и не будет

Числа «насколько ты спасён», рейтингов, соревнования с другими, серий с потерей
прогресса. Основание — `docs/VISION.md` §2, коротко: считаем сделанное, а не то,
кем человек стал.

## Хранение

Данные лежат в браузере через `window.storage`, если он доступен; иначе — в памяти
на время сессии. **Кнопка «Сохранить день» обязательна** — без неё запись
не переживёт перезагрузку.

Для постоянного хранения на своей машине это надо переделать: либо на файл JSON
рядом, либо сразу на бэкенд из этапа 4 ROADMAP. Для проверки замысла на месяц
хватит как есть.

## Критерий, назначенный заранее

Через месяц смотрим не «понравилось или нет», а факт: **сколько дней из тридцати
заполнено и какие параметры не заполнились ни разу**. Пустой параметр — это либо
неудачный вопрос, либо не моя тема. Оба вывода полезны.

Если заполнено меньше десяти дней — замысел не работает в этой форме,
и это нормальный результат эксперимента.
